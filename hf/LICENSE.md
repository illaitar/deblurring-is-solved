# Terms of the sources

The tables (`data/`) are measurements made by the benchmark and are released under CC BY 4.0.

The viewer images (`img/`) contain frames of the following test sets, and outputs of published methods computed from
them. Each source keeps its own terms:

| Test set | Terms stated by its authors |
|---|---|
| GoPro (Nah et al., CVPR 2017) | CC BY 4.0 |
| REDS (Nah et al., CVPR Workshops 2019) | CC BY 4.0 |
| RealBlur-J and RealBlur-R (Rim et al., ECCV 2020) | CC BY 4.0 |
| BSD (Zhong et al., ECCV 2020 and IJCV 2023) | no licence stated for the data |
| DVD (Su et al., CVPR 2017) | no licence stated for the data |

Method outputs are shown for comparison. The methods' code and weights keep the terms of their own repositories.
